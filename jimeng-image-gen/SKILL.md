# 即梦图片生成

使用即梦 Seedream 4.5 模型进行 AI 图片生成。

## 工具选择规则（必须遵循）

**判断依据：对话上下文中是否已有图片（用户上传的、或之前生成的）且用户要求在此基础上修改。**

- **用 text_to_image**：从零开始创作，纯文字描述生成全新图片
- **用 image_to_image**：对话中已有图片（包括之前刚生成的），用户要求修改、调整、变换风格、添加元素等

典型判断示例：
| 场景 | 正确工具 | 原因 |
|------|---------|------|
| "画一只猫" | text_to_image | 从零生成 |
| "给这个企鹅戴个帽子"（上下文有企鹅图） | **image_to_image** | 基于已有图片修改 |
| "把背景改成蓝色"（上下文有图片） | **image_to_image** | 基于已有图片修改 |
| "换成水彩风格"（上下文有图片） | **image_to_image** | 风格转换 |
| "重新画一张完全不同的" | text_to_image | 用户明确要全新创作 |

**关键：当你之前刚用 text_to_image 生成了图片，用户接着说"改一下XX"/"加个XX"/"换成XX风格"，你必须用 image_to_image，并将上一次返回的 IMAGE_URL 作为 image_url 参数传入。**

## 工具说明

### 文生图

`mcp__claude-code__image_jimeng__text_to_image` — 根据文字提示词生成图片

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| prompt | ✅ | - | 图片描述提示词，建议用英文以获得最佳效果 |
| size | ❌ | 2K | 图片尺寸，建议使用默认的 `2K`。自定义分辨率（如 `2048x2048`）需满足总像素 ≥ 3686400 |
| response_format | ❌ | url | `url` 返回图片链接，`b64_json` 返回 base64 编码 |
| watermark | ❌ | false | 是否添加水印 |

### 图生图

`mcp__claude-code__image_jimeng__image_to_image` — 基于参考图和提示词生成新图片

| 参数 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| prompt | ✅ | - | 描述期望的变化或目标效果 |
| image_url | ⚠️ | - | 单张参考图 URL（与 image_urls 二选一，至少提供一个） |
| image_urls | ⚠️ | - | 多张参考图 URL 数组（与 image_url 二选一） |
| size | ❌ | 2K | 同上 |
| response_format | ❌ | url | 同上 |
| watermark | ❌ | false | 同上 |

## 响应格式

工具返回纯文本，包含：
- 状态标记（✅ 成功 / ❌ 失败）
- 使用的参数回显（提示词、模型、尺寸等）
- 图片 URL（`IMAGE_URL: https://...`）

示例：
```
[image-jimeng/text_to_image]
✅ 文生图成功！

提示词: a cute cat
模型: ...
尺寸: 2K

🔗 图片链接 (upstream, may expire):
IMAGE_URL: https://...
```

请将图片 URL 以 Markdown 图片格式展示给用户：`![描述](url)`

## 常见使用场景

| 用户意图 | 推荐工具 | 关键判断 |
|---------|---------|---------|
| "画一张图" / "生成一张XX图片" | text_to_image | 无参考图，从零生成 |
| "帮我设计一个logo" | text_to_image | 无参考图，从零生成 |
| "给这个图加个帽子" / "改一下背景" | image_to_image | 上下文已有图片，要修改 |
| "换成水彩/像素/卡通风格" | image_to_image | 上下文已有图片，要变换风格 |
| "在这张图基础上改成XX" | image_to_image | 明确说"这张图"/"在此基础上" |
| "重新画一张完全不同的" | text_to_image | 用户明确要全新创作 |

## 注意事项

- 图片生成需要约 10-15 秒，请告知用户耐心等待
- 图片 URL 有效期约 24 小时，请提醒用户及时保存
- 不要传 `output_path` 参数（该路径为服务端文件系统，客户端不可访问）
- 不要传 `model` 参数（服务端已配置最优模型）
- `size` 建议不传或使用默认 `2K`，不要使用小分辨率（如 512x512）
- 图生图必须提供 `image_url` 或 `image_urls`，否则会报错
- 提示词建议使用英文，中文也支持但英文效果更好
